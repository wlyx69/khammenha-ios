# خمّنها — تطبيق آيفون (غلاف للعبة الويب)

هذا المشروع يحوّل لعبة الكلمات (ملف `App/Resources/www/index.html`) إلى تطبيق آيفون أصلي بسيط: شاشة واحدة فيها متصفح مدمج يعرض اللعبة من داخل التطبيق بدون إنترنت.

## كيف تطلع ملف الـ IPA

بناء تطبيقات الآيفون يحتاج ماك وبرنامج Xcode. بدل ما تشتري ماك، المشروع يبني نفسه على سيرفرات GitHub مجانًا:

1. ارفع هذا المجلد على مستودع GitHub (فرع `main`).
2. أي رفع جديد يشغّل البناء تلقائيًا (Actions → Build unsigned IPA)، ويأخذ 5 إلى 10 دقائق.
3. بعد ما يخلص، افتح صفحة Releases في المستودع وحمّل `Khammenha-unsigned.ipa` من آخر إصدار (يفتح من الآيفون مباشرة).
4. وقّع الملف بأداتك (ESign أو Sideloadly أو AltStore أو شهادة خارجية) وثبّته.

لتشغيل البناء يدويًا بدون رفع: Actions → Build unsigned IPA → Run workflow.

## رابط مباشر ثابت للـ IPA (لمتاجر التوقيع)

بعض متاجر وخدمات التوقيع تطلب رابطًا مباشرًا ينتهي بـ `.ipa` بدون تحويلات. هذا الرابط ثابت ويتحدث تلقائيًا مع كل بناء:

`https://raw.githubusercontent.com/wlyx69/khammenha-ios/main/dist/Khammenha-unsigned.ipa`

(رابط Releases يحوّل إلى خادم آخر، وبعض الخدمات ما تقبله.)

## تحديث اللعبة

استبدل `App/Resources/www/index.html` بالنسخة الجديدة وارفع. كل شيء (الكود والكلمات) داخل هذا الملف الواحد.

## تغيير الاسم والأيقونة

- الاسم اللي يظهر تحت الأيقونة: `CFBundleDisplayName` في `project.yml`.
- معرّف التطبيق: `PRODUCT_BUNDLE_IDENTIFIER` في `project.yml` (أدوات التوقيع عادة تغيّره بنفسها).
- الأيقونة: استبدل `App/Resources/Assets.xcassets/AppIcon.appiconset/icon-1024.png` بصورة 1024×1024 مربعة بدون زوايا دائرية (النظام يقصّها بنفسه).
- رقم الإصدار: `MARKETING_VERSION` و`CURRENT_PROJECT_VERSION` في `project.yml`.

## ملاحظات

- الملف الناتج غير موقّع عمدًا؛ التوقيع يتم عندك.
- التوقيع بحساب Apple ID مجاني يعيش 7 أيام ثم يحتاج إعادة توقيع؛ الشهادات الخارجية تعيش لين آبل تسحبها.
- للنشر العام لاحقًا: TestFlight أو App Store عبر حساب مطور (99 دولارًا سنويًا)، ونفس المشروع يصلح لهما بعد إضافة التوقيع.
